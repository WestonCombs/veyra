▥ Cancel Group MicsSETUP

JUST ONCE PER DEVICE

Make yourself at home.

Browsers require a trusted HTTPS connection to share a microphone. This hub creates its own private certificate for your local network.

  1. Download the hub’s certificate.

    This public certificate lets your device recognize this hub. Only install it on devices you own, after comparing the fingerprint below with the host screen.

    Download certificate ↓
  2. Trust it on this device.

    Choose your device’s instructions below. You may need to fully close and reopen your browser afterward.

  3. Connect your microphone.

    Have the six-digit room code ready, then open the secure mic page.

Open secure mic page →
Windows · Chrome / Edge

Open the downloaded .crt → Install Certificate → Current User → Place all certificates in the following store → Browse → Trusted Root Certification Authorities → Next → Finish. Confirm the certificate’s name is “Cancel Group Mics - Private LAN CA”.

iPhone / iPad · Safari

Download using Safari. Open Settings → Profile Downloaded (or General → VPN & Device Management) → install the certificate profile. Then General → About → Certificate Trust Settings → enable full trust for the hub’s CA. Return to Safari and open the secure mic page. Keep Safari visible while using the mic.

Android · Chrome

In Settings, search for “Install a certificate”. Under security credentials, install the downloaded certificate as a CA certificate. The menu names vary by device. Then open the secure mic page in Chrome. A managed device may block CA installation.

macOS · Safari / Chrome

Open the .crt in Keychain Access, add it to the login keychain, open its details, expand Trust, and set “When using this certificate” to Always Trust. Reopen your browser.

Firefox / Linux

Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import. Select the .crt and trust it to identify websites. On Linux with Chromium, import it in the browser’s certificate manager under Authorities, or your distribution’s trusted CA store.

Verify with the host · SHA-256 fingerprint

__FINGERPRINT__

The certificate key stays in the hub’s .runtime folder. Remove this CA from your device’s trusted certificates when you no longer use the hub. Never share the .runtime folder.

Can’t reach the secure page? Check the host firewall, Wi-Fi client isolation, and whether both devices are on the same network.
